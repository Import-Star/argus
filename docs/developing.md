# Developing Argus

Argus is small and plain TypeScript, so your own Claude Code agent can extend it to fit how you work. Building
from source, running it locally, the architecture and the repo's conventions are in
[DEVELOPING.md](https://github.com/Import-Star/argus/blob/main/DEVELOPING.md) on GitHub. For plugins, start with
[Writing a plugin](plugins/writing.md).
